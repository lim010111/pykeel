# 10: `pykeel run` CLI와 설정

**What to build:** 한 번 실행하고 끝나는 CLI다. `pykeel run <작업 디렉터리> "<지시문>"`으로 09의 루프를 무인 실행한다. 설정에서 모델(기본값 `gpt-6.2-sol`), reasoning effort(기본값 low), 모델 호출 횟수 상한, 누적 토큰 상한, 명령 시간 제한, 메모리 상한을 읽어 핵심 모듈에 넘긴다. 사용자는 값만 정한다. API 키는 환경 변수로만 읽는다(`.env`는 `uv run --env-file .env`로 넣는다). 안전 규칙은 핵심 모듈이 지키므로, CLI와 설정에는 샌드박스를 끄거나 상한을 우회하는 경로를 만들지 않는다. 상한 값에 기본값을 채워 넣지도 않는다.

**Blocked by:** 08 시간 초과·메모리 정리, 09 루프

**Status:** ready-for-agent

- [ ] `pykeel run <작업 디렉터리> "<지시문>"`이 루프를 끝까지 돌리고, 끝나면 종료 이유와 trace 위치를 알려 준다
- [ ] 모델과 reasoning effort의 설정 기본값이 `gpt-6.2-sol`과 low다
- [ ] 상한 값은 설정에서 그대로 넘기고, CLI나 설정 코드가 기본값을 채우지 않는다
- [ ] 샌드박스를 끄거나 상한을 우회하는 옵션이 없다
- [ ] API 키는 환경 변수로만 읽고, 키가 없으면 실행 전에 알려 준다
- [ ] 정책 테스트: 상한이 설정에 없거나 0이면 API를 부르지 않고 거절된다
