# 08: 시간 초과·메모리 상한·강제 종료 때 프로세스를 정리한다

**What to build:** 무인 실행 장치의 나머지다. 명령이 시간 초과되면 그 명령과 자식 프로세스가 모두 정리되고, 결과에 시간 초과로 표시된다. 메모리 상한은 프로세스 트리 전체에 걸리고 swap으로 빠져나가지 않는다. 하네스가 강제로 죽어도 샌드박스 안 프로세스가 남지 않는다. plan.md의 미룬 결정 "bwrap 세부 설정, 메모리 제한과 kill 방식"을 여기서 정하고 닫는다. 시간 제한과 메모리 상한 값을 받는 시그니처도 여기서 정해지고, 10이 설정에서 그 값을 넘긴다. bwrap의 `--die-with-parent`를 쓴다면, 이 옵션은 bwrap을 띄운 프로세스가 아니라 스레드가 끝날 때 동작한다는 점을 설계 메모에 남긴다(v2에서 다시 확인).

**Blocked by:** 06 샌드박스 bash
