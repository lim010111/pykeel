# 01: 비밀값 검사를 pytest와 pre-commit hook에서 돌린다

**What to build:** 커밋될 수 있는 파일 전체(추적 중인 파일과, 무시되지 않은 새 파일)에서 키 모양 문자열과, 설정되어 있다면 실제 키 값을 찾는다. 같은 검사를 pytest와 pre-commit hook 양쪽에서 돌린다. hook은 index에 올라간 내용을 본다. 찾은 값은 출력하지 않고 파일, 줄, 규칙 이름만 알린다. 규칙은 plan.md "원칙 > 비밀값" 절을 따른다. 저장한 응답과 curl 출력은 이 검사가 들어온 뒤에 픽스처로 커밋한다.

**Blocked by:** 없음(바로 시작할 수 있음)

**Status:** ready-for-agent

- [x] 커밋될 수 있는 파일 전체에서 키 모양 문자열을 찾는다
- [x] 비밀값 이름의 환경 변수가 설정되어 있으면 그 실제 값도 찾는다
- [x] 찾은 값을 출력하지 않는다
- [x] pytest의 정책 테스트로 이 저장소 전체를 검사한다
- [x] pre-commit hook이 index 내용을 검사하고, 저장소에 둔 hook 디렉터리로 연결된다
- [x] 검사가 통과한 상태로 main에 병합된다
