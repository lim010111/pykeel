# 07: 샌드박스 경계를 확인하는 정책 테스트

**What to build:** 샌드박스가 실제로 막고 있는지 확인하는 정책 테스트다. 06의 실행 함수를 그대로 불러, 막혀야 할 일이 샌드박스 안에서 모두 실패하는지 본다. 경로는 호스트 기준 절대 경로로 지정한다. 샌드박스 안의 `~`는 안쪽 `HOME` 값으로 풀리므로, `~/.ssh`로 검사하면 홈이 보이는 상태에서도 통과할 수 있다. 환경 변수 검사에는 실제 키가 아니라 가짜 값을 쓴다. 테스트에는 근거 문서로 샌드박스 조사 보고서를 링크한다.

**Blocked by:** 06 샌드박스 bash

**Status:** ready-for-agent

- [ ] `cmd.exe` 실행이 실패한다. WSL이 아니면 이 검사를 건너뛴다
- [ ] D-Bus 소켓 접근이 실패한다
- [ ] 호스트 절대 경로로 지정한 홈 디렉터리의 `.ssh` 읽기가 실패한다
- [ ] 하네스 프로세스에 설정한 API 키 모양의 환경 변수가 샌드박스 안에서 보이지 않는다
- [ ] 샌드박스 안에서 네트워크 연결이 실패한다
- [ ] 테스트가 샌드박스 조사 보고서를 근거로 링크한다
