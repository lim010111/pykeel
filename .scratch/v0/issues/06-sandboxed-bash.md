# 06: bash 명령 하나를 샌드박스 안에서 실행한다

**What to build:** tools 모듈의 첫 경로다. 명령 하나를 bwrap 샌드박스 안의 작업 사본에서 실행하고 결과를 돌려준다. 샌드박스에는 허용 목록에 있는 것만 넣는다: `/usr`(읽기 전용)와 그에 딸린 symlink, `/proc`, `/dev`, 크기를 제한한 `/tmp`, 작업 사본. 홈, `/mnt`, `/run`은 넣지 않고 네트워크는 끈다. 환경 변수는 모두 비운 뒤 허용 목록(PATH, HOME, LANG 등)만 넘긴다. 원본 저장소는 건드리지 않는다. 모듈 사이클 1단계의 실제 데이터는 샌드박스 조사 보고서에 이미 있다. 모델에게 보일 bash function tool 정의(이름, 설명, 인자)도 여기서 정한다. 시간 초과와 메모리 상한은 08에서 다룬다.

**Blocked by:** 없음(바로 시작할 수 있음)

**Status:** ready-for-human

- [ ] 샌드박스 없이 명령을 실행하는 경로가 없다
- [ ] 샌드박스 안에서 허용 목록 밖의 경로(홈, `/mnt`, `/run`)가 보이지 않고, 네트워크가 막혀 있다
- [ ] 샌드박스 안 명령은 허용 목록에 있는 환경 변수만 본다. API 키 환경 변수는 보이지 않는다
- [ ] 명령은 작업 사본에서 돌고, 실행 뒤에도 원본 저장소는 바뀌지 않는다
- [ ] 결과에 종료 코드, 소요 시간, 출력, 잘리기 전 출력 길이가 있다
- [ ] bash function tool 정의가 있다
- [ ] 동작 테스트가 있다
- [ ] 설계 메모(tools): bash 결과를 모델에게 보여 주는 형식(종료 코드 표시, 긴 출력을 자르는 방식), bash 호출 사이에 작업 디렉터리와 환경 변수가 이어지는지와 그 사실을 모델에게 알리는 방법
- [ ] 설계 메모에 예측과 실제 절을 쓴다
