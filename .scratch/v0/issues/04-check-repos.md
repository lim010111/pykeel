# 04: 확인용 저장소 2~3개를 만든다

**What to build:** v0 완료 기준 1에서 에이전트가 끝까지 풀 작은 저장소 2~3개다. 저장소마다 실패하는 테스트가 하나 있고, 지시문 한 줄로 고칠 수 있는 크기다. 샌드박스에는 `/usr`만 들어가므로 테스트는 시스템 python3와 표준 라이브러리만으로 돈다. 이 저장소들은 나중에 과제 세트에 넣지 않는다. 넣더라도 개발 과제로만 넣는다. v0을 만들며 실패를 여러 번 들여다볼 문제이기 때문이다.

**Blocked by:** 없음(바로 시작할 수 있음)

**Status:** ready-for-agent

- [ ] 저장소 2~3개가 있고, 저장소마다 실패하는 테스트가 하나 있다
- [ ] 각 저장소의 테스트가 시스템 python3와 표준 라이브러리만으로 돈다(가상환경, pytest, 네트워크 없이)
- [ ] 저장소마다 에이전트에게 줄 지시문과, 테스트를 돌리는 명령이 적혀 있다
- [ ] 고칠 수 있다는 것을 확인했다. 정답은 저장소 안에 남기지 않는다
- [ ] 과제 세트용이 아니라는 표시가 있다
